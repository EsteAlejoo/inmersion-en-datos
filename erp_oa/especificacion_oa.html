1. Documento de salida — Plantilla HTML vigente Archivo: erp_oa/oa_plantilla_v5.html

Fuente única de verdad del formato OA

El documento de salida real y vigente es erp_oa/oa_plantilla_v5.html. Esta especificación documenta campos, reglas de negocio y estructura de datos. Cualquier cambio de formato/layout se aplica únicamente en el HTML; esta especificación describe el qué, el HTML el cómo.

ElementoDescripción

Exportación ExcelPlantilla equivalente disponible en erp_oa/OA_plantilla_v5.xlsx. Incluye fórmulas de cálculo desde dosis/100L y hoja de desglose por cuartel.

tipo_maquina String(50) opt Equipo de aplicación. Default texto: "PULVERIZADORA".
agronomo String(100) opt Nombre del ingeniero agrónomo responsable técnico que firma la orden.
reingreso_hrs Integer opt Tiempo de reingreso en horas. Default 24 h (política interna). Embarazadas/lactancia siempre 48 h.
indicaciones Text opt Observaciones o instrucciones adicionales para el aplicador. Se imprime en sección "Considerar".
estado Enum ✓ Estados: borrador (editable, no imprimible) → confirmada (bloqueada, imprimible) → anulada (inactiva). Transición solo hacia adelante.
ha_totales Decimal(8,2) calc Σ ha_efectivas de todos los cuarteles. Se calcula y persiste al confirmar.
litros_totales Decimal(10,2) calc ha_totales × mojamiento_Lha. Litros de caldo total a preparar.
maquinadas_totales Decimal(8,2) calc litros_totales / capacidad_estanque. Número total de estanques a preparar.

Campo Tipo Req. Descripción / Fórmula

producto_id FK Integer ✓ FK → productos. Único por OA (no se repite el mismo producto).

4. Especificación de campos — Cuarteles de la OA (OA_Cuarteles) Una fila por cuartel incluido
Campo Tipo Req. Descripción / Fórmula
oa_id FK Integer ✓ FK → ordenes_aplicacion. Cascade delete.
cuartel_id FK Integer ✓ FK → cuarteles. Único por OA (no se repite el mismo cuartel).

5. Reglas de negocio y validaciones

R001 — Incompatibilidad Winspray + Azufre

No se puede emitir una OA que contenga simultáneamente Winspray (aceite mineral) y Azufre Thiolux Jet. Separar un mínimo de 30 días calendario entre ambas aplicaciones. Error bloqueante.

R002 — Incompatibilidad Exirel + formulaciones EC/OD

Exirel 200 SC no debe mezclarse con Winspray ni ninguna formulación EC u OD (aceites, emulsiones). Error bloqueante al intentar agregar ambos a la misma OA.

R003 — Borneo solo en Naranja (uso restringido en Limón)

Borneo 500 SC tiene carencia de 70 días en Limón y ASOEX. Advertencia cuando especie = Limón. No bloqueante pero requiere confirmación explícita.

R004 — Alerta plazo emisión

Si fecha_inicio_aplicacion − fecha_emision < 2 días, se imprime alerta roja "MENOS DE 2 DÍAS" en el PDF. No bloquea la emisión pero queda registrado.

R005 — Carencia ASOEX prevalece sobre etiqueta para exportación

Cuando mercado_destino incluye China, UE o USA, usar carencia_asoex en lugar de carencia_etiqueta. Si no hay valor ASOEX, usar etiqueta. Mostrar ambas columnas en el documento.

R006 — Numeración correlativa por predio

El num_oa se genera automáticamente: prefijo 2 letras (SP, KT, PA) + guión + número de 3 dígitos. Jamás reutilizar ni modificar un número emitido.

R007 — Mojamiento según tipo de aplicación (sugerido)

El sistema sugiere el mojamiento automáticamente según el tipo de aplicación seleccionado. El usuario puede modificarlo. Los valores sugeridos están en la tabla §6.

R008 — Estado "confirmada" es irreversible

Una OA confirmada no se puede editar. Solo se puede anular. Una OA anulada no puede reactivarse. Toda modificación a una OA confirmada requiere crear una nueva OA.

R009 — Agrupación de cuarteles contiguos

Cuando una OA incluye cuarteles con números correlativos, mostrar rangos agrupados en lugar de listar individualmente. Regla: si cuartel[i+1] = cuartel[i] + 1, formar rango inicio–fin. Casos especiales: si todos los cuarteles del predio → "Todos los cuarteles". El detalle con ha por cuartel siempre se muestra como chips secundarios. Ej: cuarteles 15, 16, 18, 19, 20 → "15–16, 18–20 (5 cuarteles)". Implementado en función JS groupNums(nums) en el HTML de plantilla.

Fecha desde fecha_emision + 1 día hábil
10. Clasificación toxicológica OMS — Requisito catálogo de plaguicidas Campo: categoria_tox_oms

Requisito de base de datos

El catálogo de plaguicidas (productos) debe incluir el campo categoria_tox_oms de tipo Enum('Ia','Ib','II','III','U','NA'), obligatorio para todos los productos registrados como plaguicidas (no requerido para fertilizantes, aunque se recomienda usar 'NA').

Valor Categoría OMS Color OA Descripción / ejemplos
Ia Extremadamente peligroso Ia DL₅₀ oral (rata) < 5 mg/kg. Ej.: Bromadiolona, Paratión-metil. Uso muy restringido en Chile.
Ib Muy peligroso Ib DL₅₀ oral (rata) 5–50 mg/kg. Ej.: Abamectina, Dimetoato, Clorpirifos. Banda NOCIVO SAG.
II Moderadamente peligroso II DL₅₀ oral (rata) 50–2000 mg/kg. Ej.: Lambda-cihalotrina, Imidacloprid, Malatión. Banda CUIDADO SAG.
III Poco peligroso III DL₅₀ oral (rata) 2000–5000 mg/kg. Ej.: Etoxazole, Glifosato. Banda CUIDADO o VERDE SAG.
U Sin riesgo agudo U DL₅₀ oral (rata) ≥ 5000 mg/kg. Ej.: Cyantraniliprole, Azufre, Aceite mineral, Piretrinas. Banda VERDE SAG.
NA No aplica NA Fertilizantes y enmiendas sin clasificación de plaguicida. Ej.: Fosfito de potasio, Nitrato de potasio.

Regla de visualización en OA

En el documento OA (hoja 2, tabla de desglose por cuartel), el encabezado de cada columna de producto lleva un borde inferior de 4 px con el color de su categoría OMS. El color se aplica mediante la clase CSS tox-[categoria] (ej.: tox-ib para Abamectina → borde rojo oscuro). Este requisito es obligatorio para cumplimiento de trazabilidad y protección de trabajadores agrícolas.

Referencia: OMS — The WHO Recommended Classification of Pesticides by Hazard and Guidelines to Classification, edición 2019.
Para consulta normativa en Chile: SAG — Resolución N° 8505/2020 (Registro de plaguicidas y clasificación de peligrosidad).
